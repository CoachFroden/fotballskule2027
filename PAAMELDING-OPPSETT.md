# Påmelding – fotballskule 2027

Dette oppsettet lagar eit Google-skjema og tilknytt rekneark i Google-kontoen som køyrer skriptet.

1. Opne https://script.google.com og opprett eit nytt prosjekt.
2. Lim inn koden frå `google-forms-oppsett.gs`.
3. Køyr `opprettFotballskule2027`, og godkjenn tilgangane.
4. Kopier lenkja til skjemaet frå loggen og legg henne inn på nettsida.
5. Del **berre skjemalenkja** offentleg. Ikkje del svararket.

Grupper: Standardfordeling er sortering etter fødselsår med om lag like mange i kvar av fem grupper. Same fødselsår blir halde samla så langt det går; grensene kan difor gi ulike gruppestorleikar. Ei endeleg gruppeinndeling bør kontrollerast av arrangør før publisering.

**Personvern:** Skjemaet samlar personopplysningar om barn og opplysningar om allergiar. Begrens tilgangen til svararket, informer om formål, lagringstid og kontaktpunkt, og slett data etter arrangementet. Unngå å sende helseopplysningar til offentleg GitHub eller usikra Firebase.
